## Задание 1. Блок-схема «Скидка в магазине»

Файл со схемой: [`docs/task1_flowchart.drawio`](docs/task1_flowchart.drawio)
(открыть: [app.diagrams.net](https://app.diagrams.net) → *File → Open* → выбрать файл, либо двойной
клик по файлу, если draw.io установлен).

### Входные данные и результат

| | Значение | Тип |
|---|---|---|
| Вход | `S` — сумма покупки, руб. | вещественное число |
| Выход | `Итог` — сумма покупки после применения скидки | вещественное число |

Правило:

* `S < 50` → скидка 0 %, итог = `S`;
* `50 ≤ S < 100` → скидка 5 %, итог = `S − S · 0.05`;
* `S ≥ 100` → скидка 10 %, итог = `S − S · 0.10`.

### Алгоритм словами

1. Начало.
2. Ввести сумму покупки `S`.
3. Проверить условие `S < 50`. Если **да** — присвоить размер скидки 0 % и перейти к шагу 7.
4. Если **нет**, проверить условие `S < 100`.
5. Если `S < 100` — **да**, присвоить размер скидки 5 %.
6. Если **нет** — присвоить размер скидки 10 %.
7. Вычислить итоговую сумму: `Итог = S · (1 − Скидка / 100)`.
8. Вывести итоговую сумму.
9. Конец.

### Используемые структуры данных

В блок-схеме используются только стандартные фигуры ГОСТ 19.701-90 / ISO 5807:

| Фигура | Назначение в этой схеме |
|---|---|
| Терминатор (скруглённый прямоугольник) | «Начало», «Конец» |
| Параллелограмм | Ввод данных (`S`) и вывод результата (`Итог`) |
| Прямоугольник | Присваивание размера скидки и вычисление итога |
| Ромб | Условия `S < 50 ?` и `S < 100 ?` с подписями «Да» / «Нет» |

Типы данных в программной реализации: `double` (вещественные числа), `int`/`bool` не требуются.
Массивы и циклы не используются — алгоритм линейный, с ветвлениями.

### Проверка схемы на наборах данных

| Набор | Ввод `S` | Путь по схеме | Скидка | Ожидаемый итог |
|---|---|---|---|---|
| **A** | 30 | `S < 50 ?` → **Да** → Скидка = 0 % | 0 % | 30.00 |
| **B** | 75 | `S < 50 ?` → **Нет** → `S < 100 ?` → **Да** → Скидка = 5 % | 5 % | 71.25 |
| **C** | 150 | `S < 50 ?` → **Нет** → `S < 100 ?` → **Нет** → Скидка = 10 % | 10 % | 135.00 |
| **D** | 49.99 | `S < 50 ?` → **Да** → Скидка = 0 % | 0 % | 49.99 |
| **E** | 100 | `S < 50 ?` → **Нет** → `S < 100 ?` → **Нет** → Скидка = 10 % | 10 % | 90.00 |

Граничные значения 49.99 и 100 тоже пройдены: видно, что границы «< 50» и «< 100» обрабатываются
строго по условию задания, а не по округлению.

## Задание 2. Индекс массы тела (BMI)

Файл: [`src/task2_bmi.cpp`](src/task2_bmi.cpp)

* **Входные данные:** `mass` — масса тела в килограммах, `height` — рост в метрах (`double`).
* **Результат:** `BMI = mass / (height · height)`.
* **Проверка ввода:** рост и масса должны быть положительными, иначе выводится сообщение об ошибке.

### Примеры работы

```
Ввод: 70 1.75
BMI = 70.00 / (1.75 * 1.75) = 22.86
Категория: норма
```

```
Ввод: 30 1.60
BMI = 30.00 / (1.60 * 1.60) = 11.72
Категория: выраженный дефицит массы
```

```
Ввод: 95 1.90
BMI = 95.00 / (1.90 * 1.90) = 26.32
Категория: избыточная масса (предожирение)
```

```
Ввод: 70 0
Ошибка: рост должен быть положительным.
```

## Задание 3. Максимум и минимум из трёх чисел

Файл: [`src/task3_max_min.cpp`](src/task3_max_min.cpp)

* **Входные данные:** три вещественных числа `a`, `b`, `c`.
* **Результат:** наибольшее и наименьшее из трёх чисел.
* Если все три числа равны — выводится отдельное сообщение «Все три числа равны».
* **Массивы не используются**: максимум и минимум находятся последовательными сравнениями.

### Алгоритм

1. Принять `a`, `b`, `c`.
2. Если `a == b && b == c` → вывести «Все три числа равны» и завершить программу.
3. Иначе `max = a`, `min = a`.
4. Если `b > max` → `max = b`; если `c > max` → `max = c`.
5. Если `b < min` → `min = b`; если `c < min` → `min = c`.
6. Вывести `max` и `min`.

### Примеры работы

```
Ввод: 3 7 -2       ->  Максимум: 7.00   Минимум:  -2.00
Ввод: 7 3 -2       ->  Максимум: 7.00   Минимум:  -2.00
Ввод: -2 5 3       ->  Максимум: 5.00   Минимум:  -2.00
Ввод: 5 5 5        ->  Все три числа равны: 5.00
Ввод: -5 -5 -5     ->  Все три числа равны: -5.00
```

Первые три набора проверяют, что результат не зависит от порядка ввода; последние два — отдельную
ветку «все равны».

## Сборка и запуск

Нужна Visual Studio с компонентами «Разработка классических приложений на C++».

```bat
scripts\build.bat
```

Скрипт сам находит Visual Studio через `vswhere`, подключает `vcvars64.bat` и компилирует оба файла
с ключами `/EHsc /std:c++17 /W4 /utf-8` (предупречений нет) в папку `build/`.

Тестовые прогоны:

```bat
scripts\run_tests.bat
```

Альтернатива — Visual Studio: *Developer Command Prompt for VS*, затем

```bat
cl /EHsc /std:c++17 /W4 /utf-8 src\task2_bmi.cpp /Fe:build\task2_bmi.exe
cl /EHsc /std:c++17 /W4 /utf-8 src\task3_max_min.cpp /Fe:build\task3_max_min.exe
```

С g++ (MinGW) команды аналогичны:

```bash
g++ -std=c++17 -Wall -Wextra src/task2_bmi.cpp -o build/task2_bmi
g++ -std=c++17 -Wall -Wextra src/task3_max_min.cpp -o build/task3_max_min
```
