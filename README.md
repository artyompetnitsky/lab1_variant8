## Задание 1. Блок-схема «Скидка в магазине»

Схема лежит в [`docs/task1_flowchart.drawio`](docs/task1_flowchart.drawio). Открыть можно в
[app.diagrams.net](https://app.diagrams.net) через *File → Open* либо двойным кликом, если
draw.io установлен. Для просмотра без редактирования есть
[`docs/task1_flowchart.png`](docs/task1_flowchart.png).

### Входные данные и результат

| | Значение | Тип |
|---|---|---|
| Вход | `S` — сумма покупки, руб. | вещественное число |
| Выход | `Итог` — сумма покупки после применения скидки | вещественное число |

Правило расчёта:

- `S < 50` → скидка 0 %, итог = `S`;
- `50 ≤ S < 100` → скидка 5 %, итог = `S − S · 0.05`;
- `S ≥ 100` → скидка 10 %, итог = `S − S · 0.10`.

### Алгоритм словами

1. Начало.
2. Ввести сумму покупки `S`.
3. Проверить условие `S < 50`. Если **да** — размер скидки 0 %, перейти к шагу 7.
4. Если **нет** — проверить условие `S < 100`.
5. Если `S < 100` — **да**, размер скидки 5 %.
6. Если **нет** — размер скидки 10 %.
7. Вычислить итоговую сумму: `Итог = S · (1 − Скидка / 100)`.
8. Вывести итоговую сумму.
9. Конец.

### Используемые структуры данных

В схеме применены только стандартные фигуры ГОСТ 19.701-90 / ISO 5807:

| Фигура | Назначение в этой схеме |
|---|---|
| Терминатор (скруглённый прямоугольник) | «Начало», «Конец» |
| Параллелограмм | ввод `S` и вывод результата |
| Прямоугольник | присваивание размера скидки, вычисление итога |
| Ромб | условия `S < 50 ?` и `S < 100 ?` с подписями «Да» / «Нет» |

Типы данных в программной реализации — `double`. Массивы и циклы не используются:
алгоритм линейный, с ветвлениями.

### Проверка схемы на наборах данных

| Набор | Ввод `S` | Путь по схеме | Скидка | Итог |
|---|---|---|---|---|
| A | 30 | `S < 50 ?` → Да → Скидка = 0 % | 0 % | 30.00 |
| B | 75 | `S < 50 ?` → Нет → `S < 100 ?` → Да → Скидка = 5 % | 5 % | 71.25 |
| C | 150 | `S < 50 ?` → Нет → `S < 100 ?` → Нет → Скидка = 10 % | 10 % | 135.00 |
| D | 49.99 | `S < 50 ?` → Да → Скидка = 0 % | 0 % | 49.99 |
| E | 100 | `S < 50 ?` → Нет → `S < 100 ?` → Нет → Скидка = 10 % | 10 % | 90.00 |

Наборы D и E проверяют границы: видно, что условия «< 50» и «< 100» обрабатываются строго
по заданию, без округления в свою пользу.

## Задание 2. Индекс массы тела (BMI)

Исходный код: [`src/task2_bmi.cpp`](src/task2_bmi.cpp)

**Входные данные:** `mass` — масса тела в килограммах, `height` — рост в метрах (`double`).
**Результат:** `BMI = mass / (height · height)`.
**Проверка ввода:** рост должен быть положительным, иначе выводится сообщение об ошибке.

### Примеры работы

```
Введите массу (кг): 70
Введите рост (м): 1.75
BMI = 22.8571
```

```
Введите массу (кг): 30
Введите рост (м): 1.6
BMI = 11.7187
```

```
Введите массу (кг): 95
Введите рост (м): 1.9
BMI = 26.3158
```

```
Введите массу (кг): 70
Введите рост (м): 0
Ошибка: рост должен быть положительным.
```

> Значение выводится без округления. Чтобы получить вид `22.86`, нужно добавить
> `#include <iomanip>` и вставить `cout << fixed << setprecision(2);` в начало `main`.

## Задание 3. Максимум и минимум из трёх чисел

Исходный код: [`src/task3_max_min.cpp`](src/task3_max_min.cpp)

**Входные данные:** три вещественных числа `a`, `b`, `c`.
**Результат:** наибольшее и наименьшее из трёх чисел.
**Особый случай:** если все три числа равны — выводится отдельное сообщение «Все три числа равны».
**Массивы не используются:** максимум и минимум находятся последовательными сравнениями.

### Алгоритм

1. Принять `a`, `b`, `c`.
2. Если `a == b && b == c` → вывести «Все три числа равны.» и завершить программу.
3. Иначе найти максимум: при `a >= b && a >= c` максимум равен `a`, иначе если
   `b >= a && b >= c` максимум равен `b`, иначе — `c`.
4. Аналогично найти минимум: при `a <= b && a <= c` минимум равен `a`, иначе если
   `b <= a && b <= c` минимум равен `b`, иначе — `c`.
5. Вывести максимум и минимум.

### Примеры работы

```
Введите три числа: 3 7 -2
Максимум: 7
Минимум: -2
```

```
Введите три числа: 7 3 -2
Максимум: 7
Минимум: -2
```

```
Введите три числа: -2 5 3
Максимум: 5
Минимум: -2
```

```
Введите три числа: 5 5 5
Все три числа равны.
```

```
Введите три числа: -5 -5 -5
Все три числа равны.
```

Первые три набора показывают, что результат не зависит от порядка ввода; последние два
проверяют отдельную ветку «все равны».
