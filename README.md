## Задание 1. Скидка в магазине

Схема в draw.io: `docs/task1_flowchart.drawio`.

Правило: `S < 50` → скидка 0 %, `50 ≤ S < 100` → 5 %, `S ≥ 100` → 10 %.

Проверка: `S = 30` → 30.00, `S = 75` → 71.25, `S = 150` → 135.00.

## Задание 2. Индекс массы тела

`BMI = mass / (height * height)`. Рост должен быть положительным.

## Задание 3. Максимум и минимум из трёх чисел

Массивы не используются. Если все три числа равны — выводится отдельное сообщение.
